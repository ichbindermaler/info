# info

Öffentliche Seiten für Kunden des Malerbetriebs Bäßgen.

Live unter **https://info.ichbindermaler.de** über GitHub Pages.

## Wichtig

Die Datei `CNAME` nicht löschen oder umbenennen — sonst fällt die
Domain ab und die Seiten sind nur noch über die github.io-Adresse
erreichbar.

## Aufbau

Einzelne HTML-Dateien ohne Build-Prozess. `index.html` liegt im Root,
damit QR-Codes ohne Dateinamen auskommen — kurze URL, gröberes
QR-Muster, bessere Lesbarkeit auf Aufklebern.

## Regeln

- Alles hier ist öffentlich lesbar, auch rückwirkend über die Historie
- Keine Kundendaten, keine internen Preise
- Dateinamen sind stabil zu halten: sie stecken in gedruckten QR-Codes
